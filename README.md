# Broken Silo

Data you can hear and see. A test press of four playable tracks, built by [Tanner Spaulding](https://tannerspaulding.com). Each track turns a public dataset into music and a moving picture you can play with.

- **Arrivals:** U.S. births per day, 2000 to 2014. Social Security Administration, via FiveThirtyEight (CC BY 4.0).
- **Twelve Hundred Springs:** Kyoto cherry full-flowering dates, 812 to 2026, compiled by Yasuyuki Aono (copyright Yasuyuki Aono), via the George Mason University peak bloom prediction project. Used for a free, non-commercial site.
- **Weathering:** daily rain and high temperature from NOAA's Global Historical Climatology Network-Daily (Menne et al. 2012, doi:10.7289/V5D21VHZ), nearest station to each place.
- **Stoops:** every Baltimore neighborhood with 60 or more lived-in homes, oldest to newest by the average year its homes were built. Real Property Information, Baltimore City (Open Baltimore, CC BY 3.0, https://creativecommons.org/licenses/by/3.0/), from the November 2025 copy in the baltimore-real-property project on GitHub, which keeps lived-in residential homes with a recorded sale. Beaver Dam quarry date from Baltimore Magazine, "Anatomy of a Baltimore Rowhome" (2025). The sounds are made in code.
