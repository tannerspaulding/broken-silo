# Broken Silo

Data you can hear and see. Each track turns a public dataset into music and a moving picture you can play with.

- **Arrivals:** U.S. births per day, 2000 to 2014. Social Security Administration, via FiveThirtyEight (CC BY 4.0).
- **Twelve Hundred Springs:** Kyoto cherry full-flowering dates, 812 to 2026, compiled by Yasuyuki Aono (copyright Yasuyuki Aono), via the George Mason University peak bloom prediction project. Used for a free, non-commercial site.
- **Weathering:** daily rain and high temperature from NOAA's Global Historical Climatology Network-Daily (Menne et al. 2012, doi:10.7289/V5D21VHZ), nearest station to each place.
